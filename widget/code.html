네이버 블로그 위젯 코드

분홍 코드 복사 버튼을 누르고, 네이버 위젯 직접등록 칸에 Ctrl+V 하면 됩니다. 이미지 주소까지 다 들어 있습니다.

  1. 네이버 블로그 관리 → 꾸미기 설정 → 레이아웃·위젯 설정
  2. 오른쪽 목록 맨 아래 위젯 직접등록
  3. 위젯명 입력 → 아래 코드 복사 버튼 → 큰 칸에 Ctrl+V → 다음 → 등록
  4. 네이버 제한(코드 2,000byte·세로 600px) 때문에 B는 3개로 나눴습니다. A → B1 → B2 → B3 순서로 등록
  5. 새 위젯을 끌어서 led견적문의 바로 뒤에 놓기 → 적용 전에 캡처 보내기
