개인정보처리방침 (SMART21업로드)

시행일: 2026년 11월 25일

‘SMART21업로드’는 유한회사 스마트21(SMART21)이 자사 유튜브 채널에 홍보 영상을 업로드하기 위해 내부적으로 사용하는 프로그램입니다. 외부 이용자를 대상으로 하지 않습니다.

1. 이용하는 정보

Google 계정 승인을 통해 YouTube Data API에 접근하며, 스마트21 채널의 영상 업로드, 썸네일 설정, 재생목록 추가, 업로드된 영상 목록 확인에만 사용합니다.

2. 보관 및 제3자 제공

승인 정보(토큰)는 회사가 관리하는 암호화된 저장소에만 보관하며, 제3자에게 제공하거나 판매하지 않습니다. 업로드 기록(일시·제목·영상 ID)만 내부 기록으로 남깁니다.

3. 승인 철회

Google 계정의 보안 설정(https://myaccount.google.com/permissions)에서 언제든지 앱 접근 권한을 해제할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책

본 프로그램은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.
